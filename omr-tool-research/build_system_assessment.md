## 2. 决策框架：什么量级才"需要"构建系统

| 项目特征 | 推荐方案 | 理由 |
|---|---|---|
| 单文件、无外部依赖 | 直接 `cl`/`g++` 编译，无需任何构建文件 | 命令短、改了重编即可 |
| 2–5 文件、纯标准库 | **Makefile**（或批处理脚本） | 避免"改一处重编全部"；但仍很轻 |
| ≥5–10 文件 / 多模块 | 需要构建系统 | 手工管理编译顺序与依赖关系易错 |
| **含重第三方依赖（OpenCV 等）** | **依赖管理（vcpkg）+ 构建系统** | 头文件/库路径/链接标记/运行时 DLL 都需要被管理 |
| 跨平台 / VS 集成 / 团队协作 | CMake 优先 | 一份配置生成多平台工程 |

**关键阈值**：是否引入构建系统，主要看两点——(a) 文件/模块数量，(b) **是否有需要"下载→编译→链接"的第三方依赖**。你的项目后者一开始就命中。

## 3. 对你规划中 MVP 的评估

| 评估维度 | 你的项目特征 | 对选型的含义 |
|---|---|---|
| 源文件数量（规划） | 5 模块，预计数十个 .cpp | 超过手写编译的舒适区 |
| 模块复杂度 | 输入解析/识别/ MusicXML I/O/ 转换/ 输出 职责分离 | 多目标（executable + 多个 lib），适合现代 CMake target 模型 |
| 跨平台需求 | **MVP 仅 Windows** | 跨平台不是驱动因素（但也不排斥） |
| 第三方依赖管理 | **OpenCV（庞大、多组件）+ libmusicxml2** | **这是决定性因素**——OpenCV 需配 include/lib 路径、按组件链接、拷贝运行时 DLL；vcpkg 负责编译与暴露路径，CMake 用 `find_package(OpenCV)` + `target_link_libraries(... OpenCV::opencv_core)` 声明式接入 |

**核心论点**：
- 即使 MVP 只跑 Windows，"是否有重依赖"已经把你推过阈值。OpenCV 不是"加一个 -I 一个 -l"就能搞定的小库——它几十个组件、需要正确的链接标记和运行时 DLL。用手写 Makefile 去接 vcpkg 装好的 OpenCV，本质是在重复造 CMake+vcpkg 已经解决的轮子，且更脆（路径硬编码、组件漏链、Debug/Release 运行时不匹配）。
- **"CMake 过度"的担忧，只在"项目停在单文件、零依赖"这个你并不会停留的形态下才成立。** 你的路线图一旦进入依赖，CMake 反而比 Makefile 更省心。

## 4. 与"更轻量方案"的对比

| 方案 | 适配你的项目？ | 说明 |
|---|---|---|
| 直接编译 (`cl main.cpp`) | ❌ 不可行 | OpenCV 进来后命令长达数百字符，且忘拷 DLL 必运行时崩 |
| Makefile | △ 勉强但脆弱 | 能管多文件；但仍需 vcpkg 提供库，且要手动写 -I/-L/-l、管运行时不匹配；无 VS 原生调试、无 preset |
| **CMake + vcpkg** | ✅ 推荐 | `find_package` 声明式接入；天然对接 VS 调试；`CMakePresets` 固化配置；可复现 |

## 5. 明确建议

1. **现在（0 源码）**：不要纠结构建系统。下一步是写**阶段 0 迷你工程**（pugixml 读谱，OpenCV 读图为选做），从第一行代码起就用 CMake——因为依赖从第一天就在。**（2026-07-13 追记：该迷你工程已用 pugixml 实现并跑通，`Pudu.exe` 打印 Stage 0 passed。）**
2. **可以用一行命令先验证环境**：装好 OpenCV 后，用 `cl /I<vcpkg>/include main.cpp /link ...` 跑通一次，确认 vcpkg 装对了；但**提交进仓库的工程用 CMake**，别把一次性命令当构建方案。
3. **降级条件（仅当）**：如果你彻底推翻多模块规划、把项目砍到 ≤3 文件且零依赖，那时 Makefile/直接编译 更简单。但你目前的路线不会这样。
4. **额外收益**：你已把"学会 CMake/vcpkg"列为转 AI 的能力目标。在这个真实项目上用起来，就是最好的练习——学习价值维度也支持早用。

**一句话**：你的"怀疑"在抽象意义上合理，但落到你"OpenCV 重依赖 + 多模块"的具体形态上，CMake + vcpkg 不是过早优化，而是恰到好处。等写出第一份带 OpenCV 的代码，它会立刻显得必要。
