## 0. 一句话定位

**五线谱图片 → MusicXML（一等输出）+ 简谱（内部投影）** 的 OMR 引擎：
图片经 oemer（音符检测）+ F3（几何音高）+ R-geo（几何时值）校正后产出 MusicXML，
再由 Pudu 内核投影为简谱。**MusicXML 是产品交付物，不是中间格式。**

## 4. MusicXML 一等输出承诺 + 验收口径（决策已定）

**产品链路**：`五线谱图片 → MusicXML（一等输出）→ 简谱（内部投影）`。
MusicXML 是用户可交付的产物，供打谱软件 / DAW / 教育生态消费，简谱由它投影。

**验收口径（扩为双项）**：

| 验收项 | 内容 | 当前状态 |
|---|---|---|
| ① 简谱正确率 | `note_pass` / `field_pass`（既有） | 83.2% / 91.6% |
| ② MusicXML 结构有效 | **music21 可读 + 可再渲染**（schema 有效、可被下游消费） | 新增验收项；当前 `<alter>`/`<tie>`/`<beam>` 天然缺失（oemer 不产）属结构缺口，随 C 路线补齐 |

**影响**：C 路线（图像符号检测）产出的 `<beam>/<accidental>/<tie>` 同时补齐简谱与
MusicXML 结构，是双受益投资。

## 6. 诚实边界（对外务必一致）

- **83.2% 是最严格数字**：联立惩罚放大，字段级 91.6% 才是单维度真实水平；
- **节奏是弱项**：残余读短/读长 348 已几何+beam 双盲封账，非短期可修；
- **图像级符号未检测**：♯/♭、梁、延音弧线 oemer 不产，当前靠几何/结构兜底；
- **2/15 页失败**：oemer 检测层崩溃（canon_p2、summer_p5），明确报错降级。
