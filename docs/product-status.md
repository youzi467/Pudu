## 0. 一句话定位

**五线谱图片 → MusicXML（一等输出）+ 简谱（内部投影）** 的 OMR 引擎：
图片经 oemer（音符检测）+ F3（几何音高）+ R-geo（几何时值）校正后产出 MusicXML，
再由 Pudu 内核投影为简谱。F3/R-geo 入口内置 **forward 溢出修复**（2026-08-10 补，
兼容层：清除 oemer voice-bridge 的 16-bit 回卷 `<forward>`，否则 music21 回写挂起）。
**MusicXML 是产品交付物，不是中间格式。**

## 4. MusicXML 一等输出承诺 + 验收口径（决策已定）

**产品链路**：`五线谱图片 → MusicXML（一等输出）→ 简谱（内部投影）`。
MusicXML 是用户可交付的产物，供打谱软件 / DAW / 教育生态消费，简谱由它投影。

**验收口径（扩为双项）**：

| ① 简谱正确率 | `note_pass` / `field_pass`（既有） | 84.5% / 91.7% |
| ② MusicXML 结构有效 | **music21 可读 + 可再渲染**（schema 有效、可被下游消费） | **可读 13/13、可再渲染 11/13**（2026-08-10 forward 溢出修复后：6/13→11/13；残余 bach_p2/bach_p3 为 voice-bridge 错位，见 §7）；`<alter>`/`<tie>`/`<beam>` 天然缺失（oemer 不产）属结构缺口，随 C 路线补齐 |

## 6. 简谱小节质量修复（决策已定：方案1 → 归因 → 方案4 + 方案2）

**投诉**：简谱输出小节时值不对、每小节节拍数不对。
**归因（2026-08-10，13 页 350 voice-measure 逐对核对）**：坏小节**主导根因 = oemer 小节
边界错位**——音符音高时值全对，只是被插/漏纵线（铁证 bach p1 开头切 2/14/4/12，正确
16/16，逐音核对全对）；**不是缺休止**（79 个欠填小节 GT rest-sum 全为 0）。音符真丢失仅
个别页（canon p1 32.6%、summer p2 17.1%、the-swan 11.5% 等，oemer 检测 dropout，
Python 不可修）。

| 方案 | 内容 | 结论 |
|---|---|---|
| **1. 拍号推断 + 注入 `<time>`** | 从既有 `<time>`/小节填充推断拍号写入 MusicXML | ✅ **已落地**（inject_time_signature，纯 Python，FROZEN 零 diff；11/11 页推断正确） |
| **归因** | 精确判定坏小节根因 | ✅ 见上，为 3/4 取舍提供依据 |
| **3. 补休止** | 欠填小节补 `<rest>` 填满 | ❌ **否决**：假休止盖在错位/丢失音符上，节拍数好看但音符更错 |
| **4. 拍号约束保守重切** | 音符流按拍号 target 贪心重切；门（碎片页 / 切点偏差>tol / 无拍号）外不改文件 | ✅ **已落地**（re_slice_measures）；**GT 验证 beatOK 100→171（+71 小节）**，6 页重切（bach p1、badinerie、prelude p1/p2、summer p1/p4），音符级质量不变 |
| **2. 节拍校验打标** | `\|fill−target\|>tol` 小节给首音符打 `<footnote>需校对：小节节拍不符</footnote>` | ✅ **已落地**（mark_meter_constraint_failures）；门失败页（canon p1、swan-lake、the-swan、bach p2/p3、summer p2/p3）兜底 |

**落地管线**（pudu_server 定点阶段）：`注入 <time> → 保守重切 → 节拍校验打标`，与 FROZEN
管线零 diff。
**边界**：重切只修「错位」，**找不回真丢失音符**（canon p1、the-swan 等仍打标兜底，不谎报）；
弱起小节（badinerie GT m0 pickup）与碎片页不重切。验证仅限既有语料同页（先不跑泛化）。

## 7. 诚实边界（对外务必一致）

- **84.5% 是最严格数字**：联立惩罚放大，字段级 91.7% 才是单维度真实水平；
- **节奏是弱项**：残余读短/读长 348 已几何+beam 双盲封账，非短期可修；
- **图像级符号未检测**：♯/♭、梁、延音弧线 oemer 不产，当前靠几何/结构兜底；
- **2/15 页失败**：oemer 检测层崩溃（canon_p2、summer_p5），明确报错降级；
- **7 页曾有 forward 溢出**（voice-2 bridge 的 16-bit 回卷，music21 回写挂起）：2026-08-10
  已在 F3/R-geo 入口内置修复（移除 51 个 corrupt `<forward>`，幂等；修复后回写 6/13→11/13，
  note_pass 无回归 83.19→83.21）。**残余 bach_p2/bach_p3 可读但不可再渲染**：oemer
  voice-bridge 把 v2 音符写到负偏移/错位，music21 导出时合成超标准时值休止符失败——与
  forward 溢出同源但更深，需 v2 重定位（改动内容，风险高），暂列为已知边界。
